# Global variables

There are a lot of global variables in this engine for you to further modify the behaviour of the game, here
are the list of global variables and their purpose.

| Name | Type | Purpose |
| --- | --- | --- |
| `CoalitionBattleLerpSpeed` | `Real` | The lerp speed of the animation in battle |
| `CoalitionUILerpSpeed` | `Real` | The lerp speed of the animation of the UI |
| `EncounterID` | `Real` | Sets the current encounter |
| `CoalitionSlamDamage` | `Real` | The amount of damage a slam deals to the player during battle |
| `CoalitionMovementNormalized` | `bool` | Whether moving digonally will move faster than moving horizontally or vertically |
| `CoalitionItemHealClearKR` | `bool` | Whether KR will be set to 0 when an item is consumed |
| `timer` | `real` | Frames elapsed since game was initalized |
