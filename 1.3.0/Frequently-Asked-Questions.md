# Frequently Asked Questions

### What platforms does this engine support?

Due to our dependency on public libraries, the supported platforms are the platforms that they support, which is potentially every platform except for HTML5.

### Which Game Maker version should I use to use this engine?

It is best to use Game Maker 2024.13+ versions as v1.0.0 was developed in it.

### What is different between Coalition Engine and other existing engines?

- This engine comes with documentation and comments to explain variables and functions.
- The engine is well optimized compared to other engines, therefore players will be less likely to experience lag.
- The codes are well formatted to enhance readibility for users to understand it's inner workings.

### I encountered a bug, how do I fix it?

File a bug report, either in the [Github Issues tab](https://github.com/CoalitionEngine/Coalition-Engine/issues) (Please label
it properly) or in the Discord server's bug report channel.<br>
Please check if the issue is resolved before filing it.

### There is a feature that isn't in the engine and it would be great to have it!

Similar to a bug report, you can file it either in the Issues tab (Please label it properly) or in the Discord server's suggestions
channel.<br>
Please check if the feature was requested (and/or denied) before filing it.

### There is a mistake in the documentation, are you illiterate?

Yes, now be a good netizen and submit it as an issue on Github or report it in the Discord server.
